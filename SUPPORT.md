Thanks for using and contributing to **SciRes**! Here is where to find help and
resources.

To build and browse the full `rustdoc` API documentation locally:

```sh
cargo doc --no-deps --workspace --open
```

## Asking Questions

- **Usage questions, ideas, and general discussion**: Check existing
  [GitHub Issues](https://github.com/Augusto-Dantas/Scires/issues) or start a
  discussion on the repository.
- **Bug reports and feature requests**: Please open an issue using the
  appropriate [issue template](https://github.com/Augusto-Dantas/Scires/issues/new/choose).
- **Security vulnerabilities**: Please follow the private reporting instructions
  in [SECURITY.md](SECURITY.md) rather than opening a public issue.
