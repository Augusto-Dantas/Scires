# Security Policy

## Supported Versions

SciRes is currently in active early development (`0.1.x`). Security fixes are
applied to the latest commit on `main` and upcoming minor releases.

| Version | Supported          |
| ------- | ------------------ |
| `0.1.x` | :white_check_mark: |
| `< 0.1` | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Instead, please report them privately using one of the following channels:

1. **GitHub Security Advisories** (preferred):
   Open a private advisory at
   <https://github.com/Augusto-Dantas/Scires/security/advisories/new>.
2. **Email**:
   Send an email to [augusto.p.dantas8@gmail.com](mailto:augusto.p.dantas8@gmail.com)
   with the subject line `[SECURITY] SciRes: <brief description>`.

Please include as much of the following information as possible to help us
reproduce and resolve the issue quickly:

- Type of issue (e.g., arbitrary code execution, path traversal, privilege
  escalation, dependency vulnerability)
- Affected crate(s) or component(s) and commit hash / version
- Step-by-step reproduction instructions or a minimal proof-of-concept
- Potential impact and any suggested remediation

## Response Timeline

- **Acknowledgment**: Within 3 business days of receipt.
- **Initial assessment**: Within 7 business days, including severity evaluation
  and next steps.
- **Disclosure**: Once a fix is available, we will coordinate disclosure with the
  reporter and credit them (unless anonymity is requested).
